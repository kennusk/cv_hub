# Claude Working Instructions — CV Hub

Это рабочие инструкции для агента Claude в проекте CV Hub — генератор CV/портфолио на основе единого YAML источника с выходом в веб-сайт и экспортом в PDF/DOCX/TXT.

## Ключевые моменты

**Стек:** Astro 5, TypeScript, YAML, Playwright, GitHub Actions.

**Язык:** Беседа на русском, код и документация остаются на английском.

**Git:** Работа только в `main`. Коммиты, пуши, мержи — исключительно при явной просьбе пользователя.

**Стиль:** Решительный, лаконичный, без переговоров о уже решённых вопросах. Вопросы только при подлинных развилках.
